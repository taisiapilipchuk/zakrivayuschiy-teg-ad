# Закрывающий тег

Учебный проект Яндекс Практикума — сайт о пути обучения, преодолении трудностей, сомнениях и маленьких победах в процессе освоения веб-разработки.

## О проекте

«Закрывающий тег» — адаптивный сайт с карточками, отражающими этапы обучения и личные переживания начинающего разработчика. Проект посвящён не только полученным знаниям, но и эмоциям, трудностям и внутренним изменениям, которые сопровождают обучение.

## Технологии

- HTML5
- CSS3
- JavaScript
- SVG

## Реализовано

- Адаптивная вёрстка
- CSS-анимации и интерактивные состояния
- Анимация лайков
- SVG-иконки
- Диалоговое окно
